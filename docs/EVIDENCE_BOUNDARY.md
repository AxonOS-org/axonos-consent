# Evidence Boundary

This repository defines and tests the AxonOS consent state-machine boundary.

## L0

Source code, unit tests, integration tests, and repository-level checks.

## L1

Bounded verification harnesses only when attached logs exist.

## L2

Measured hardware evidence only when raw benchmark artifacts exist.

## L3

External validation, lab evidence, or regulatory evidence.

This repository does not claim L3 validation.
