# Security Policy

Security reports for `axonos-consent` should be sent to:

security@axonos.org

## Relevant issues

Please report:

- consent bypass;
- withdrawal bypass;
- capability bypass;
- malformed frame acceptance;
- replay acceptance;
- unsafe observation-gate behavior;
- panic or denial-of-service in bounded parser paths;
- incorrect evidence-level claims.

## Sensitive data

Do not include raw neural data, patient data, private keys, device secrets, or
proprietary firmware in the initial report.

## Current status

PGP key publication is pending.

High-sensitivity reports should request an encrypted intake path first.

## Non-claim

This repository is a draft reference implementation. It is not a clinical
deployment or regulatory submission.
